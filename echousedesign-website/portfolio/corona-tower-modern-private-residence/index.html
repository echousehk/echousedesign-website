Corona Tower

A modern private residence shaped around calm, connected living. The 1,600 sq.ft. renovation combines a light neutral palette, warm timber accents, integrated storage and layered lighting to give each room a more considered daily rhythm.

Project Type

Design Direction

A modern home with a calm, continuous material language.

The living, dining and kitchen zones are visually connected through pale surfaces, restrained timber detailing and carefully placed lighting. A television feature wall, full-height storage and a streamlined kitchen allow the larger shared spaces to feel composed while remaining practical for everyday use.

Private rooms carry the same considered approach through tailored cabinetry, window-side work surfaces and compact wet-area planning. The result is a modern home that balances display, storage, comfort and clean spatial flow without unnecessary visual noise.
